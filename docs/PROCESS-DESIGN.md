# Scrollfortælling — 5. oktober 2026

Forsiden har fire automatiske scrollkapitler, og processiden har fem. Grafik holdes synlig, mens teksten passerer. Ingen klik eller scroll-lås. Headerens faktiske højde bestemmer afstanden til grafikken. Reduceret bevægelse slår tegneanimation og sticky grafik fra.

Om-siden bruger portræt, årstal, forbindelse mellem kunde og håndværk samt materialegrafik. Tømrersiden bruger originale billeder, tag- og samlingsgrafik og konkrete ydelseskort. Alle oprindelige afsnitstekster bevares.

Titler: undersider 33–60 px, mindre afsnitsoverskrifter og balancerede linjeskift. Anmeldelser har konsistent kortstruktur, tydelige afsendere, datoer og kildelinks. Officielt Trustpilot-logo uden anmeldelsesantal.

Kontrol: build, TypeScript og ESLint bestået. HTML og interne links på alle otte sider bestået. Alle sider kontrolleret for vandret tekstoverflow på mobil (390 px) og desktop (1280 px). Visuelle stikprøver af de ændrede sektioner på smal og bred skærm. Automatisk faseskift og mobilafstand til header verificeret i browseren. Tidligere Lighthouse-tal er fra før denne opdatering og er ikke genmålt.
